SF-Porter for Poco X3 Pro (vayu)
A custom automation tool to port Sailfish OS (via Halium 11.0) to the Xiaomi Poco X3 Pro (codename: vayu).

Features
*Automates Halium build environment setup
*Generates droid-configs templates
*Extracts vendor blobs for libhybris
*Packages flashable TWRP .zip files

Usage
./scripts/sf-porter.sh
